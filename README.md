# Heart Failure Clinical Data Analysis

## 📊 Project Overview
This project focuses on exploratory data analysis (EDA) and visualization of heart failure clinical records to identify patterns and key factors associated with patient mortality (death events).  
The analysis was conducted using Python on Google Colab, emphasizing data cleaning, aggregation, and visual interpretation.

---

## 🎯 Objectives
- Analyze clinical characteristics of patients with and without death events
- Compare key numerical features such as age, ejection fraction, and serum creatinine
- Identify correlations between clinical variables and mortality outcomes
- Visualize insights to support data-driven conclusions

---

## 📁 Dataset
- **Source:** Heart Failure Clinical Records Dataset
- **Format:** CSV
- **Records:** 299 patients
- **Features:** 13 clinical attributes (age, ejection fraction, serum creatinine, blood pressure, etc.)

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

---

## 🔍 Analysis Workflow
1. Load and inspect the dataset
2. Perform data cleaning and validation
3. Group data based on death events
4. Compute statistical aggregations (mean, count)
5. Generate visualizations:
   - Age distribution
   - Feature comparison by death event
   - Correlation heatmap

---

## 📈 Key Results
- Patients who experienced death events tend to have:
  - Higher average age
  - Higher serum creatinine levels
  - Lower ejection fraction
- Strong correlations are observed between several clinical variables and mortality outcomes
- Visualization results highlight potential risk factors associated with heart failure patients
